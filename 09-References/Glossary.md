# Terminlar lug‘ati

| Termin | Ta’rif |
|---|---|
| Hub | Lokal biznes qoidalari, API va database’ni boshqaruvchi markaziy server |
| POS | Buyurtma va to‘lov uchun xodim interfeysi |
| Admin | OWNER uchun menyu, xodim, report va sozlama interfeysi |
| TV | Buyurtma navbati va tayyor holatini ko‘rsatuvchi ekran |
| Modular monolith | Bitta deployable jarayon ichida aniq modul chegaralariga ega arxitektura |
| Microservices | Mustaqil deploy va data ownership’ga ega kichik xizmatlar arxitekturasi |
| Pairing | Yangi qurilmani Hub bilan nazoratli bog‘lash |
| Opaque token | Ma’nosi client tomonidan ochilmaydigan va server session’iga reference qiluvchi token |
| Idempotency | Bir xil so‘rov takrorlansa qo‘shimcha side effect yuz bermasligi xususiyati |
| Stop-list | Vaqtincha sotilmaydigan variant/modifier ro‘yxati |
| Shift | Kassa faoliyatining ochilish va yopilish oralig‘i |
| Z-report | Yopilgan smenaning yakuniy moliyaviy xulosasi |
| Current | Joriy kod/test daliliga ega arxitektura yoki funksiya |
| Partial | Qisman mavjud yoki tashqi tekshiruv talab qiladigan funksiya |
| Proposed | Kelajak uchun konsept yoki rejalashtirilgan dizayn |
